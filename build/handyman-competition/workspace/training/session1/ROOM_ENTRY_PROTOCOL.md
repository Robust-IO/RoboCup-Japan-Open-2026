# 房间到达与家具观察分离

统一规则（Session1、2、4已知源家具，以及Session3搜索任务）：

1. 接收任务后导航进入目标房间。
2. 当前底盘中心的地图坐标进入房间region且距离区域边界至少0.5米才完成入房阶段；取消这一阶段剩余路径并正常移交控制。
3. 状态机发送Room_reached。
4. 已知家具任务才开始导航到最近可达且视线无遮挡的源家具候选位姿；搜索任务才前往主搜索点并扫描，必要时使用备用点。
5. 识别、接近、抓取、搬运及放置保持原流程。

`room_entry_navigation.py`是现有导航的入房专用适配器，导航途中逐次检查当前TF是否进入房间。不再等待家具目标点的位置/朝向到位。家具候选点仅作为进入目标房间的规划方向，最终接近家具另属navigate_source阶段。

若启动任务时已经深入指定房间至少0.5米，直接完成入房阶段并上报，不额外前往房间中心。控制器精度、速度、地图和正常家具导航完成标准不变。

候选排序在跨房间路径规划前和真正接近家具前均按当前机器人位置执行：先排除静态地图不可达/视线被挡的候选，再比较栅格路径长度。路径最短不等于直线距离最近。

Session3的连续扫描明确在search阶段导航到第一个主搜索点，避免入房早报后在门口直接开始扫描。

停止控制器识别新的入房导航子进程，并等待取消确认。此次是协议时序修正，不能把之前完成的单轮实测当作修正后版本的实测结果。
