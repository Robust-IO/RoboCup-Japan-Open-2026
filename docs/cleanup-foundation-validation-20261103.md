## 已实施

1. **发送端时间契约**：桥接器支持 source/receive 两种明确模式。Cleanup 默认 source，
   保留 Unity 的 sec/nanosec，记录源时间、接收时间及差值。source 模式拒绝缺失或零时间戳，
   不混入接收时间；receive 兼容模式同批 TF 统一时间。Cleanup 默认 use_sim_time=false。
   本机 Unity 工程及 Build/SIGVerseConfig 均已开启 setUpRosTimestamp；Header.Update 使用 Unix
   时间并减去时间同步偏差，RobotPubCameraImage 在读取纹理前更新时间，RobotPubTf 在 LateUpdate
   读取关节并更新时间。原始时间比接收时间更接近采集，但尚不能证明渲染、深度、TF完全同步。
2. **头部观测时间**：所有头部命令建立图像时间边界。迟到的运动期间图像不会作为停稳后的
   跟踪/取物样本；原有完整世界几何和目的地阶段隔离仍保留。
3. **可修正取物假设**：保留 Pick 之前经现有时间一致性检查的世界方向，转头方向是暂定假设。
   持续物体证据可支持另一条方向；若多条受支持方向对应不同物体实例，保持未确定。
   不用 Pick 后的放置/行走手势补取物答案。不同来源不混合做时间一致性检查；深度方向、
   原点与图像平面保持同帧，取消“平均多帧方向配最后一帧平面”的混合几何。
4. **手/臂来源**：取消 handedness 分数抬高方向置信度；消息加入 geometry_source。
   已确认伸指且同帧肘腕可关联时，恢复肘至指尖几何，避免伸展检查失败后只能使用短手指段。
   关联距离沿用腕部裁剪范围，并测试远处手、不可见肘及非有限坐标。
5. **实际头部范围与速度**：原 ±1.2rad 人工限制替换为 SIGVerse HSRCommon.cs 的关节定义：
   pan [-3.839,1.745]、tilt [-1.570,0.523]，头部速度上限 1rad/s。
   统一命令出口限制范围，并根据当前关节与目标转角延长动作/观测等待时间。
6. **尺度敏感性**：统一使用 640/320/160 图像金字塔；所有帧、类别使用同一路径，置信度仍0.25。
   同类重复框在原始图像坐标按 NMS 合并，不能把三个尺度算作三个时间投票。
   detection_scales 参数可设为 [640] 做原流程对照。记录各帧推理耗时与尺度。
7. **版本追踪**：run-cleanup-current.sh 检查新消息字段并打印已安装控制器、检测器、桥接器 SHA256。
